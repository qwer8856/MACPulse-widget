# MacPulse Widget

原生 macOS 菜单栏监控与桌面小组件，显示 CPU、内存、磁盘占用及供电功率。菜单栏位于屏幕右上角，桌面小组件支持小、中、大三种尺寸，应用不会创建置顶悬浮窗。

当前版本：**2.1.0**。安装后的应用和小组件名称均为 **“系统状态”**。

## 下载安装

**[下载安装包：MacPulse Widget 2.1.0（M 系列 Mac）](https://github.com/qwer8856/MACPulse-widget/releases/download/v2.1.0/MACPulse-Widget-v2.1.0-macOS-arm64.zip)**

[版本发布页与校验文件](https://github.com/qwer8856/MACPulse-widget/releases/tag/v2.1.0)

需要 Apple Silicon Mac（M 系列）和 macOS 14 或更新版本。

1. 从 [Releases](https://github.com/qwer8856/MACPulse-widget/releases) 下载并解压 ZIP 安装包。
2. 将“系统状态.app”拖入“应用程序”文件夹。
3. 启动“系统状态”，屏幕右上角菜单栏会显示 CPU 和内存占用。点击可展开磁盘、功率、内存压力等详情。
4. 需要桌面小组件时，在桌面空白处右键，打开“编辑小组件”，搜索 **“系统状态”**，选择尺寸并添加。

当前安装包使用本地临时签名，未经 Apple 开发者签名和公证，首次打开可能被 macOS 安全策略拦截；该限制不因从 GitHub 下载而消失。仅在本机验证过，其他机型的功率数据支持情况可能不同。

## 使用与更新

菜单栏默认显示 CPU 和内存占用；取消勾选“菜单栏显示 CPU 和内存”可切换为只显示图标，该选择会保留。点击菜单栏可查看详细指标、打开活动监视器或请求刷新桌面小组件。

菜单栏程序运行期间，CPU 和内存约每秒采样一次；磁盘数据约每 15 秒读取，功率约每 5 秒读取一次，传感器本身的更新可能更慢。退出菜单栏程序后，桌面小组件仍由系统独立调度采样。菜单栏与桌面小组件采样时间不同，读数可能暂时不同。

更新时先从菜单栏退出应用，再从 [Releases](https://github.com/qwer8856/MACPulse-widget/releases) 下载新版，替换“应用程序”中的旧版并启动。使用本仓库相同标识的版本升级通常可保留已添加的小组件。

## 数据与限制

| 指标 | 统计方式 |
| --- | --- |
| CPU | 全核心平均占用；菜单栏按约 1 秒的间隔采样，桌面小组件在系统调度时采样约 0.6 秒 |
| 内存 | 应用内存、系统固定内存与压缩池实际大小之和，排除文件缓存及可清除匿名页；单位 GiB |
| 内存压力 | 直接读取系统压力等级，判断内存紧张程度应结合此项 |
| 磁盘 | 内置 APFS 主容器总容量减去共享可用空间；单位 GB |
| 功率 | 读取设备供电侧遥测，单位 W；不是累计耗电量，不含外接显示器 |

- **桌面小组件不保证每秒刷新。** 内置 1 秒后的刷新请求，实际执行频率由 macOS 的刷新预算和节能策略决定；菜单栏的采样不受 WidgetKit 刷新预算限制。
- 功率读数依赖机型及供电状态，部分设备不支持，会显示 `--`；传感器自身也可能约一分钟才更新一次。
- 功率读数超过 3 分钟会隐藏；整份采样超过 15 分钟显示“等待更新”，避免把旧数据当作当前状态。
- 程序不联网、不记录运行日志，不需要辅助功能或录屏权限。
